Shadow runtime v4.2

State is saved in this browser. Export a snapshot to move it to another device.

Set the objective

The target is frozen after creation. Changing it creates a new objective version; prior state history stays attached. Source checks are your attestations; this browser app cannot independently authenticate the real-world source.

Record an observed state change

A changed value is recorded as progress. PASS requires the frozen target to be met and both baseline and after evidence to be present.

Add a discovery route

Runtime v4.2 selects exactly two materially different routes per generation. After both fail to advance the target, the old generation locks until the blocker is reassessed.

Record route execution evidence

This records source attestation and an artifact hash; it does not independently authenticate the source.
